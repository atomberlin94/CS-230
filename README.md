# CS-230
The Gaming Room was the client for this project, and they wanted to expand their game Draw it Or Lose It from an Android app to a web-based application that could support multiple platforms and users at the same time. The software needed to make sure game names, team names, and player names were unique while also being secure and able to grow as more users joined. I think one thing I did well in this project was explaining my design choices and comparing different operating platforms. Taking the time to complete the design document first also helped me understand how everything would fit together before writing the code. If I could revise part of my work, I would add more detail about security and how the application could continue to perform well as more users sign up. I interpreted the client's needs by focusing on the requirements they provided and making sure the design supported those goals. Considering the user's needs is important because the software has to solve the client's problem and be easy for everyone to use. Throughout this project, I approached software design by first understanding the requirements, then planning the overall structure before thinking about implentation. I will continue using design documents in future projects because they help organize ideas and making development smoother.
